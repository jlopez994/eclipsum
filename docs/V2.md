## Operativa

- CDN: `https://cdn.jlh.app/eclipsum/` — sirve `eclipsum.apk` y `eclipsum-beta.apk` (verificado 200). `latest_apk_url` apunta ahí por defecto.
- Para avisar de una actualización: publicar `latest_version_code` en RC (`firebase deploy --only remoteconfig`). El script `publish-apk.sh` imprime los valores RC tras cada subida.
- Checks: `npm run selfcheck` y `npm run typecheck`.
- Build APK: `expo prebuild` + gradle con el JDK de Android Studio (`/Applications/Android Studio.app/Contents/jbr/Contents/Home`).
